# RAPP Platform™

> **RAPP** — the Rapid Agent Prototype Platform — is a progressive AI-agent platform that teaches and runs the Microsoft AI stack across three self-contained tiers.

Brainstem (local) → Spinal Cord (Azure) → Nervous System (M365). This is the ecosystem umbrella; start at the [RAPP Installer](https://github.com/kody-w/rapp-installer).
